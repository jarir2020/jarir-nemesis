Introduction

Nemesis is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling.

Installation

Requirements (v3.0.0 Enterprise)

  • PHP: >= 8.1 (8.2+ Recommended)
  • Composer: >= 2.0
  • Database: MySQL 5.7+ / MariaDB 10.3+
  • Extensions: bcmath, ctype, curl, dom, fileinfo, json, mbstring, openssl, pcre, pdo, tokenizer, xml, ziparchive

Create a new project via Composer:

composer create-project jarir/nemesis-framework my-app

Or clone the repository:

git clone https://github.com/jarir2020/jarir-nemesis.git my-app
cd my-app
composer install

Configuration

Configuration files are stored in the config directory. Use .env for environment specific variables.

cp .env.example .env
php nemesis key:generate

Directory Structure

  • app/: Contains core application logic (Controllers, Models, etc).
  • src/: The framework core code (do not edit).
  • config/: Configuration files.
  • database/: Migrations and Seeds.
  • public/: Web entry point & assets.
  • routes/: Route definitions.
  • storage/: Logs, compiled views, file storage.
  • tests/: Application tests.

Routing

Routes are defined in routes/route.php. See Detailed Documentation.

Basic Routing

use Nemesis\Support\Facades\Route;

Route::get('/hello', function () {
    return 'Hello World';
});

Route::post('/submit', [FormController::class, 'store']);

Route Parameters

Route::get('/user/{id}', function ($request, $id) {
    return "User ID: {$id}";
});

Route Groups

Group routes to apply middleware or prefixes:

Route::group(['middleware' => 'auth', 'prefix' => 'admin'], function ($router) {
    $router->get('/dashboard', [AdminController::class, 'index']);
});

Named Routes

Route::get('/profile', [UserController::class, 'show'])->name('profile');

Fallback Routes

Route::fallback(function () {
    return view('errors.404');
});

Middleware

Filter HTTP requests entering your application. See Detailed Documentation.

Global Middleware

Runs on every request:

protected $middleware = [
    \App\Http\Middleware\CheckForMaintenanceMode::class,
];

Route Middleware

Assign to specific routes via an alias:

protected $routeMiddleware = [
    'auth' => \App\Http\Middleware\Authenticate::class,
];

Route::get('/admin', [AdminController::class, 'index'], ['auth']);

Middleware Groups

Assign multiple middleware via a single key (e.g., 'web', 'api'):

protected $middlewareGroups = [
    'api' => ['throttle:60,1', 'auth:api'],
];

Route::group(['middleware' => 'api'], function($router) {
    // ...
});

CSRF Protection

Cross-Site Request Forgery usage. See Detailed Documentation.

HTML Forms

<form method="POST" action="/profile">
    <input type="hidden" name="_token" value="<?= csrf_token() ?>">
    <!-- ... -->
</form>

AJAX Requests

<meta name="csrf-token" content="<?= csrf_token() ?>">

Excluding URIs

Add URIs to $except in VerifyCsrfToken.php.

Controllers

Controllers group related request handling logic. See Detailed Documentation.

class UserController extends Controller
{
    public function show($id)
    {
        return User::findOrFail($id);
    }
}

Dependency Injection

Type-hint dependencies in the constructor or methods:

public function __construct(UserRepository $users)
{
    $this->users = $users;
}

Validation

Validate incoming request data. See Detailed Documentation.

$validated = $request->validate([
    'email' => 'required|email',
    'name' => 'required|string|min:3'
]);

Requests & Responses

Accessing Input

$name = $request->input('name');
$input = $request->all();

Attaching Headers

return response($content)
            ->header('Content-Type', 'application/json')
            ->cookie('name', 'value', $minutes);

Database

Nemesis provides a fluent query builder. See Detailed Documentation. 

use Nemesis\Core\Database;

$users = Database::table('users')->get();

Query Builder

$users = Database::table('users')
             ->where('votes', '>', 100)
             ->get();

Migrations

Migrations are version control for your database. See Detailed Documentation.

Generate migration:

php nemesis make:migration create_flights_table

Run migrations:

php nemesis migrate:run

Seeding

Populate your database with test data. See Detailed Documentation.

Create seeder:

php nemesis make:seeder UserSeeder

Run seeders:

php nemesis db:seed

Eloquent Models

Interact with your database using object-oriented models. See detailed docs for Models, Relationships, and Query Scopes.

namespace App\Models;
use Nemesis\Core\Model;

class Flight extends Model {}

Relationships

public function user() {
    return $this->belongsTo(User::class);
}

Query Scopes

public function scopeActive($query) {
    return $query->where('active', 1);
}

Security

Protect your application using built-in security features. See detailed docs for Authentication, Authorization (RBAC), and Encryption.

Authentication

use Nemesis\Http\Session;
Session::set('user_id', 1);

Authorization

use Nemesis\Auth\Gate;
if (Gate::allows('update-post', $post)) { ... }

Encryption

use Nemesis\Security\Crypt;
$encrypted = Crypt::encrypt('secret');

Broadcasting

Broadcast events over WebSockets or logs. See Detailed Documentation. 

use Nemesis\Broadcasting\LogBroadcaster;
(new LogBroadcaster)->broadcast(['news'], 'Update', ['msg' => 'Hello']);

Multi-Tenancy

Segment data per tenant using Tenant Scopes.

class Post extends Model {
    use TenantScope;
}

Queues

Offload slow tasks to background workers. See Detailed Documentation.

Dispatching

Queue::push(new SendEmailJob($user));

Worker

Run the worker to process jobs:

php nemesis queue:work

Task Scheduling

Define your schedule in app/Console/Kernel.php. See Detailed Documentation.

protected function schedule($schedule)
{
    $schedule->call(function () {
        DB::table('recent_users')->delete();
    })->daily();
}

Add the following Cron entry to your server:

* * * * * php /path-to-project/nemesis schedule:run >> /dev/null 2>&1

Artisan CLI

A powerful Artisan-inspired CLI. See Detailed Documentation.

Command Description
list List all available commands
help Display help for a command
make:controller Create a new controller class
make:model Create a new Eloquent model class
make:migration Create a new migration file
migrate Run the database migrations
db:seed Seed the database with records

Ecosystem & Plugins

Nemesis 3.0 introduces a robust plugin architecture. See Detailed Documentation.

DebugBar

In-browser toolbar for debugging requests, SQL, and memory. See Detailed Documentation.

Installation: php nemesis plugin:enable DebugBar

Features: Query logging, Request timing, Exception tracking.

Cloud Storage

Abstract file system supporting local and S3 storage. See Detailed Documentation.

Installation: php nemesis plugin:enable CloudStorage

Usage: Storage::disk('s3')->put('file.jpg', $content);

Swagger API Docs

Auto-generates OpenAPI documentation from attributes. See Detailed Documentation.

Installation: php nemesis plugin:enable Swagger

Access: /api/documentation

IDE Helper

Autocomplete generation for Models and Facades. See Detailed Documentation.

Installation: php nemesis plugin:enable IdeHelper

Run: php nemesis ide-helper:generate

Audit Logging

Enterprise-grade model change tracking. See Detailed Documentation.

Installation: php nemesis plugin:enable Audit

Usage: Add use AuditTrait; to your models.

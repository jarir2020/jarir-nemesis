## 💎 New "Enterprise" Pillar Highlights

### 1. Robust Plugin System (Sidecar Architecture)
Nemesis 3.0.0 introduces a world-class plugin system that allows deep framework extension without bloating the core:
- **Sandboxed Execution**: Permission-based security restricts plugin access to the Filesystem, Database, and Network.
- **Dependency Isolation**: Isolated autoloading ensures no version conflicts between plugins.
- **CLI First**: Manage the entire lifecycle (`create`, `list`, `enable`, `disable`) via the Nemesis CLI.

### 2. The "Essential Five" Plugin Suite
We are shipping with 5 production-ready enterprise plugins:
- **🔍 DebugBar**: A real-time HUD for SQL logs, request timing, and memory usage.
- **☁️ CloudStorage**: Unified API for Local and AWS S3 storage via Flysystem.
- **📜 Swagger**: Instant OpenAPI documentation and interactive UI served at `/api/documentation`.
- **🛠️ IDE Helper**: Autocomplete generation for Models and Facades to supercharge DX.
- **🕵️ Audit**: Enterprise-grade change tracking for models, logging "who, when, and what" changed.

### 3. Core Framework Fortification
The engine has been reinforced for mission-critical applications:
- **Model Intelligence**: Added static `create()` factories and `ArrayAccess` implementation for seamless data manipulation.
- **Advanced Routing**: Support for recursive Middleware Groups, Named Routes, and Fallback handlers.
- **Security Hardening**: Global CSRF protection for all stateful requests and 20+ robust validation rules.

### 4. Premium Documentation Suite
Documentation is no longer just "README" files. We’ve implemented a custom rendering engine:
- **Beautiful Rendering**: A standalone Markdown viewer (`viewer.html`) handles all documentation.
- **Syntax Highlighting**: Integrated **Prism.js** for enterprise-standard highlighting of PHP, Bash, and JSON.
- **Seamless Navigation**: Smart link interception keeps you inside the premium experience as you navigate between guides.

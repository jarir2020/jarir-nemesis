# Examples Gallery

Nemesis ships an isolated `examples/` gallery for learners, vibe coders, and anyone who wants a ready-made starting point without changing the normal framework workflow.

## What is included

- MVC starters for content and dashboard apps
- API starters for JSON-first applications
- Plugin starters for framework extensions
- Extension starters for bridge packages and adapters
- Module starters for self-contained application features
- 32 starter packs total, with room to grow as real-world patterns emerge

## Safety rules

- The gallery is not autoloaded.
- Nothing is registered automatically in a fresh app.
- You can delete the gallery at any time without breaking your project.
- These files exist to teach structure and save setup time.

## Browse from the CLI

```bash
php nemesis examples:list
```

Introduction

Nemesis is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling.

Installation

Clone the repository and install dependencies:

git clone https://github.com/jarir/nemesis.git my-app
cd my-app
composer install

Configuration

Configuration files are stored in the config directory. Use .env for environment specific variables.

cp .env.example .env
php nemesis key:generate

Directory Structure

  • app/: Contains core application logic (Controllers, Models, etc).
  • src/: The framework core code (do not edit).
  • config/: Configuration files.
  • database/: Migrations and Seeds.
  • public/: Web entry point & assets.
  • routes/: Route definitions.
  • storage/: Logs, compiled views, file storage.
  • tests/: Application tests.

Routing

Routes are defined in routes/route.php.

$router->get('/hello', function () {
    return 'Hello World';
});

Middleware

Filter HTTP requests entering your application.

$router->get('/admin', 'AdminController@index')->middleware('auth');

CSRF Protection

Nemesis automatically generates a CSRF "token" for each active user session. This token is used to verify that the authenticated user is the one actually making the requests to the application.

<form method="POST" action="/profile">
    <input type="hidden" name="_token" value="<?php echo csrf_token(); ?>">
    ...
</form>

Controllers

Controllers can group related request handling logic into a single class.

class UserController extends Controller
{
    public function show($id)
    {
        return User::findOrFail($id);
    }
}

Requests & Responses

Accessing Input

$name = $request->input('name');
$input = $request->all();

Attaching Headers

return response($content)
            ->header('Content-Type', 'application/json')
            ->cookie('name', 'value', $minutes);

Validation

Validate incoming data easily:

$validated = $request->validate([
    'title' => 'required|min:5',
    'body' => 'required',
]);

Database

Interact with databases using raw SQL or Query Builder.

$users = DB::select('select * from users where active = 1');

Query Builder

$users = DB::table('users')
             ->where('votes', '>', 100)
             ->get();

Migrations

Generte migration:

php nemesis make:migration create_flights_table

Structure:

Schema::create('flights', function ($table) {
    $table->id();
    $table->string('name');
    $table->string('airline');
    $table->timestamps();
});

Run:

php nemesis migrate:run

Seeding

Populate database with test data.

php nemesis make:seeder UserSeeder
php nemesis db:seed

Eloquent Models

class Flight extends Model {}

$flight = new Flight;
$flight->name = 'London to Paris';
$flight->save();

Relationships

public function user()
{
    return $this->belongsTo(User::class);
}

Query Scopes

Define common sets of constraints that you may easily re-use via Global Scopes or Local Scopes.

// Global Scope example
User::addGlobalScope('age', function ($builder) {
    $builder->where('age', '>', 200);
});

Authentication

if (Auth::attempt($credentials)) {
    return redirect('/dashboard');
}

Authorization (RBAC)

Nemesis features a Role-Based Access Control system. You can define Roles and Permissions in the database.

Usage

// Check permission
if ($user->can('edit-post')) {
    // ...
}

// In Controller
$this->authorize('update', $post);

Management

Use the provided CLI tools or Models to manage roles:

$role = Role::create(['name' => 'writer']);
$permission = Permission::create(['name' => 'edit-post']);

$role->givePermissionTo($permission);
$user->assignRole('writer');

Encryption

Nemesis provides an AES-256-CBC encrypter via the OpenSSL PHP extension.

use Nemesis\Security\Crypt;

$encrypted = Crypt::encrypt('Hello World');

$decrypted = Crypt::decrypt($encrypted);

Broadcasting

Broadcast events over WebSockets.

php nemesis websockets:serve

Multi-Tenancy

Automatically scope queries to the current tenant.

TenantManager::setTenant(1);

Queues

Offload slow tasks (like emailing) to background queue workers.

Dispatching

Queue::push(new SendEmailJob($user));

Worker

Run the worker to process jobs:

php nemesis queue:work

Task Scheduling

Define your schedule in app/Console/Kernel.php.

protected function schedule($schedule)
{
    $schedule->call(function () {
        DB::table('recent_users')->delete();
    })->daily();
}

Add the following Cron entry to your server:

* * * * * php /path-to-project/nemesis schedule:run >> /dev/null 2>&1

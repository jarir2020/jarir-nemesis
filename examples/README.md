# Nemesis Examples Gallery

These examples are optional starter packs for learners, fast coders, and AI-assisted prototyping.

They are intentionally isolated from the normal application boot path:
- they are not autoloaded,
- they are not registered automatically,
- and they can be deleted without affecting a working app.

## How to use them

1. Browse the catalog:
   ```bash
   php nemesis examples:list
   ```
2. Open the example you want.
3. Copy only the files you need into your app.
4. Customize the copied files to match your project.

## Gallery

- `mvc/blog` - Blog-style MVC starter with controller, model, route, and view.
- `mvc/dashboard` - Admin dashboard MVC starter with cards and summary widgets.
- `api/users-api` - JSON API starter with controller, routes, and resource.
- `api/content-api` - Content API starter for articles and publishing flows.
- `plugins/audit-plugin` - Framework plugin starter for audit-style hooks.
- `plugins/seo-plugin` - Framework plugin starter for metadata and sitemap hooks.
- `extensions/frontend-bridge` - Framework extension starter for frontend integration.
- `extensions/storage-adapter` - Framework extension starter for storage adapters.
- `modules/blog-module` - Application module starter for content teams.
- `modules/shop-module` - Application module starter for commerce teams.
